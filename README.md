# IX COMMUNITY

IXコミュニティの活動紹介・テーマトーク記録を掲載する静的Webサイトです。

## 公開方法（GitHub Pages）
1. GitHubで `ix-community` という名前の新しいPublicリポジトリを作成します。
2. このフォルダ内のファイルとフォルダを、リポジトリ直下にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、Branchを `main`、Folderを `/ (root)` にしてSaveします。
5. 数分後、`https://<GitHubユーザー名>.github.io/ix-community/` で公開されます。

## 更新方法
- トップページの活動紹介：`index.html`
- テーマ一覧：`index.html` の `THEME TALKS` セクション
- テーマ詳細：`talks/` にHTMLファイルを追加
- デザイン：`style.css`
- モバイルメニュー等：`script.js`

## 公開前の確認
参加者の氏名・写真・個人の発言を掲載する場合は、本人およびコミュニティ運営側の許可を確認してください。現状のサンプルは、共有されたテーマと意見の範囲で作成しています。
