# IX COMMUNITY — Official Site Draft

IX Communityの公式サイト公開を想定した静的Webサイト案です。

## 構成
- `index.html` — トップページ
- `about.html` — 設立背景・目的
- `activities/index.html` — 活動紹介
- `theme-talks/index.html` — テーマトーク一覧
- `theme-talks/01.html` — テーマトーク第1回の記録
- `reports/index.html` — 活動報告（掲載準備中）
- `contact.html` — 問い合わせ案内（窓口確認中）
- `assets/` — CSS・JavaScript

## 公開前に必ず確認すること
1. IX Community運営側による全ページの文言確認・承認
2. IX HoldingsおよびIX Communityの正式ロゴ・ブランドガイドラインの使用許可と差し替え
3. 正式な問い合わせ先、運営主体表記、プライバシーポリシーの掲載要否
4. 写真・氏名・所属・発言を掲載する場合の本人および関係者の同意
5. 活動内容・実績・開催日・協力先などの事実確認
6. 独自ドメインを使う場合の取得・DNS設定

## GitHub Pagesでの公開
1. GitHubでPublicリポジトリを作成（例：`ix-community`）
2. このフォルダ内のファイルとフォルダをリポジトリ直下へアップロード
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選択
4. 公開URLと全ページの表示・リンクを確認

## 注意
このデータは公式公開を想定した制作案です。承認を得ているとの前提で構成していますが、本文・表記・ロゴ・連絡先等の最終的な公開判断は運営側の確認を経てください。公式ロゴや写真素材は無断で作成・代用せず、正式データの支給後に反映してください。
